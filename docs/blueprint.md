# **App Name**: CampusGuard

## Core Features:

- Sensor Data Simulation: Simulate sensor data for air quality (PM2.5, CO2, VOCs), temperature, humidity, and noise levels across different campus zones.
- Real-time Zone Monitoring: Display real-time data from simulated sensors for each campus zone on a dashboard.
- Color-Coded Heatmaps: Visualize campus zones on a map with color-coded indicators (Green = Safe, Red = Unsafe) based on environmental data.
- Threshold-Based Alerts: Trigger alerts when sensor data exceeds WHO guidelines for air quality, temperature, humidity, and noise levels.
- Trend Charts: Display historical trends of sensor data for each zone using daily/weekly charts.
- Predictive AQI Alerts: Utilize a tool to predict future AQI levels for each zone and generate alerts (e.g., 'Zone B likely unsafe in 2 hours').
- Automated and Manual Emergency Alerts: Send automated email alerts to registered students and teachers in case of emergency breakouts, with a manual override process.

## Style Guidelines:

- Primary color: Calm blue (#4A8FE7), evoking a sense of safety and reliability. The hue relates to clear skies, and to clear thinking and planning.
- Background color: Light desaturated blue (#E8F0FE), creating a clean and unobtrusive backdrop.
- Accent color: Vibrant purple (#A663CC), providing contrast and highlighting important elements such as alerts and interactive components.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a modern, machined, objective, neutral look; suitable for both headlines and body text.
- Use clear, minimalist icons to represent different sensor types and environmental conditions.
- Design a clean and intuitive dashboard layout with clear sections for real-time data, maps, charts, and alerts. Favor a card-based approach to the presentation.
- Implement subtle animations for data updates and transitions to enhance user experience. Example: a smooth transition whenever the heatmaps refresh.
